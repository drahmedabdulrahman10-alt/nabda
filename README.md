# نَبضة

تطبيق أندرويد عربي لتنظيم اليوم: مهام اليوم، مهام يومية متكررة، تذكير بصلة الرحم، وحكمة لكل يوم، مع التاريخين الميلادي والهجري.

- **يعمل بدون حساب وبدون إنترنت.** كل البيانات محفوظة على الجهاز نفسه.
- **خفيف وسريع.** نسخة الإصدار حوالي 1.5 ميجابايت.
- **إضافة مهمة في ثانية.** اكتب في الشريط أسفل شاشة اليوم واضغط إدخال.
- واجهة عربية كاملة من اليمين لليسار، ووضع داكن يتبع النظام.

## التشغيل

المتطلبات: [Android Studio](https://developer.android.com/studio) (أو JDK 17+ مع Android SDK).

```bash
./gradlew assembleDebug
```

الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

لبناء نسخة إصدار مصغّرة:

```bash
./gradlew assembleRelease
```

بدون إعداد مفتاح توقيع، تُوقَّع نسخة الإصدار بمفتاح debug المحلي، وهذا يصلح للتثبيت على جهازك فقط. للنشر عرّف المتغيرات `KEYSTORE_PATH` و`STORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`.

## المساعد الذكي (اختياري)

يمكن إملاء عدة مهام بالصوت أو النص ليقسّمها التطبيق تلقائيًا. الميزة تحتاج مفتاح Gemini أو OpenRouter خاصًا بك تضيفه من الإعدادات، ويُحفظ على جهازك فقط. بقية التطبيق لا يتصل بالإنترنت.
